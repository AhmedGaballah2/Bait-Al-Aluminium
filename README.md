# بيت الألومنيوم

E-commerce web application for browsing aluminum products and placing orders.

## Tech Stack

### Frontend
- React
- Vite
- Axios

### Backend
- Django
- Django REST Framework
- PostgreSQL

### Infrastructure
- Docker
- Railway

## Features

- Product catalog
- Categories
- Product reviews
- Shopping cart
- Order management
- Order tracking
- Admin dashboard
- Rate limiting
- Cloudflare Turnstile
